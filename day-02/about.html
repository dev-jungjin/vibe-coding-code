소개

소프트웨어 개발자로 일하며, 대한민국인공지능에듀테크협회에서 AI 풀스택 웹개발을 가르치고 있습니다. 수강생이 첫날부터 모바일 기기와 PC 모두에서 열리는 웹페이지를 완성하고, 점진적으로 데이터베이스·인증·배포까지 경험하도록 과정을 구성합니다.

강의의 중심은 바이브코딩입니다. 막연히 "예쁜 사이트 만들어줘"라고 맡기는 대신, 목표(만들 것)·제약(지킬 것)·예시(모양새)를 분명히 적은 뒤 AI와 페어 프로그래밍하는 실무 습관을 훈련합니다.

강의에서 지키는 원칙

원칙 1

처음부터 모바일 퍼스트

고정 폭으로 만든 뒤 나중에 반응형을 덧붙이지 않습니다. 첫 프롬프트부터 viewport와 768px 기준 레이아웃을 제약으로 넣습니다.

원칙 2

지시문은 3요소로

목표, 제약, 예시를 갖춘 프롬프트가 결과물의 오차를 줄입니다. 두루뭉술한 요청은 불필요한 복잡도를 불러옵니다.

원칙 3

같은 서비스 위에 쌓기

매 회차 새로운 프레임워크로 갈아타지 않습니다. 게시판 한 개를 끝까지 키우며 데이터, 인증, 인가, 배포를 연결합니다.

원칙 4

보이는 결과로 확인하기

코드를 작성한 뒤에는 브라우저와 개발자 도구로 직접 검증합니다. 확인과 수정 요청을 반복하는 것이 바이브코딩의 호흡입니다.

다루는 기술

프론트엔드 HTML, CSS, Next.js, TypeScript, Tailwind CSS
백엔드 / 데이터 Supabase, Prisma, REST API
협업 / 배포 Git, GitHub, Vercel, Claude Code
디자인 기준 GS Retail 토큰, 모바일 퍼스트 RWD

교육 설계

교안, 슬라이드, 실습 코드 저장소 구축

수강생이 회차 폴더만 열어 독립 실행할 수 있도록 영문 케밥케이스 경로와 일차별 완성 코드를 함께 준비합니다.

일상

자전거, 뮤지컬, 그리고 두 마리의 가족

백반과 수육을 좋아하고, AI 에이전트와 기술 철학 관련 책을 읽습니다. 강아지와 고양이를 한 마리씩 기르고 있습니다.
