# 2일차 — 말로 시켜서 나만의 소개 사이트 만들기

1일차 단일 자기소개 페이지를 홈, 소개, 프로젝트 세 페이지로 확장한 **다중 페이지 정적 사이트**입니다. 공통 반응형 내비게이션으로 페이지를 연결하고, AI에게 일을 시킬 때 쓰는 프롬프트 3요소(목표·제약·예시)를 `prompts.md` 에 함께 담았습니다.

## 학습 목표

- 두루뭉술한 지시와 구조화된 지시의 차이를 체감합니다.
- 목표(만들 것), 제약(지킬 것), 예시(모양새)를 갖춘 프롬프트로 여러 페이지를 생성합니다.
- 브라우저로 결과를 확인하며 점진적으로 수정 요청을 반복합니다.

## 폴더 구조

```text
day-02/
├── index.html      # 홈 — 프로필, 기본 정보, 책, 반려동물
├── about.html      # 소개 — 강의 원칙, 기술, 최근의 일
├── projects.html   # 프로젝트 카드 목록
├── style.css       # 공통 스타일 (헤더 포함)
├── design.md       # GS Retail 디자인 토큰 및 반응형 규칙
├── prompts.md      # 이 사이트를 만들 때 사용한 3요소 프롬프트
├── images/         # 프로필, 책 표지, 반려동물 사진
└── README.md
```

## 실행 방법

이 폴더는 Node.js 설치가 필요하지 않습니다.

1. `index.html` 을 브라우저로 엽니다.
2. 또는 이 폴더에서 아래 명령으로 로컬 서버를 켭니다.

```bash
npx --yes serve .
```

브라우저에서 표시된 주소로 접속한 뒤, 창 너비를 줄이고 늘이며 헤더와 카드 레이아웃이 바뀌는지 확인하세요.

## 화면 구성

- **모바일 (768px 미만)**: 상단 로고 아래 홈 / 소개 / 프로젝트 알약 메뉴가 한 줄로 이어지고, 본문은 단일 열 카드 스택입니다.
- **태블릿 / 데스크톱 (768px 이상)**: 헤더는 왼쪽 로고 + 오른쪽 메뉴, 홈·소개는 왼쪽 320px 프로필 컬럼과 오른쪽 본문 컬럼의 2열 그리드입니다. 프로젝트는 2열 카드 그리드입니다.

디자인 토큰은 1일차와 같습니다. 배경 `#F4F5FB`, 카드 `#FFFFFF`, 강조 `#00D4EA`, 주 색 `#1E2530`, 모서리 18px, 서체 Pretendard.
